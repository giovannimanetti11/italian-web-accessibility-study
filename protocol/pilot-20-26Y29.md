Purpose: validate scanner robustness, deterministic page sampling and output shape before the 100-domain pilot.

## Domain-level outcome

20 selected domains:

- 7 completed
- 13 domain-level failures

Failure classification:

- 9 non-public/unresolved destinations rejected by the network guard
- 2 HTTP 403 homepages
- 1 HTTP 526 failure
- 1 browser navigation failure

The low completion rate is specific to this deliberately rank-stratified pilot, which reaches
deep into the current Tranco tail. It must not be interpreted as a reachability estimate for
the Italian web.

## Scanner issues discovered and fixed

### Malformed redirect ports

Two sites exposed redirect/final URLs containing malformed port-like strings. URL
canonicalization previously raised `ValueError`.

Fix: malformed ports are now rejected deterministically and converted to controlled scan
outcomes rather than crashing parsing.

### User-Agent bias

An early smoke test used a custom research User-Agent and triggered a 403 on W3C.

Fix: use the default User-Agent of the pinned Chromium build and record the exact value in
the result.

### Functional-page false positives

Raw substring matching incorrectly classified examples such as:

- `Cartier` as `cart`
- `cartuccia` / `Cartosio` as `cart`
- a product slug containing `contatti` as a contact page

Fix: functional hints must match an entire normalized path segment or the beginning of that
segment. The real-world H2O regression case now selects `/it/carrello`.

### Low-value boilerplate

Cookie/privacy/legal/terms/sitemap/feed URLs are excluded from representative-page
sampling so a seeded slot is not wasted on boilerplate when content pages are available.

## Final sampler validation (v3)

The seven reachable domains were rescanned with the stabilized sampler.

- 7/7 domains completed
- 31 page slots selected
- 27 pages successfully evaluated
- 4 selected internal URLs returned non-success status
- 1 sampled domain performed a cross-registrable-domain redirect

Selection reasons across the 31 slots:

- homepage: 7
- functional: 3
- content: 4
- deep: 6
- seeded: 6
- fallback: 5

The v2 -> v3 comparison changed only the intended H2O functional selection. No new
obvious sampling false positive was observed in the seven manually inspected manifests.

## Cross-domain redirects

`migliori-casinoonline.it` redirected to `sangiusepperoma.it`.

The original `.it` domain remains the sampling unit, while the destination is explicitly
recorded. Primary and sensitivity analyses must report cross-domain redirects separately;
the final paper must not silently treat the destination as if it were the original site.

## Performance observation

The initial 20-domain run completed in about 142 seconds. The seven reachable-domain v3
validation completed in about 115 seconds.

Large sitemap discovery appeared to dominate several domains, but the original pilot did
not separately instrument discovery time. Timing fields have therefore been added for all
future runs:

- homepage load
- sitemap discovery
- total discovery
- total domain scan

No discovery timeout/budget has been changed yet; that decision should be data-driven from
the next pilot.

## Decision after pilot 20

Retain:

- maximum five pages per domain
- rendered-homepage + sitemap discovery
- deterministic selection
- no unrestricted recursive crawl
- separate `violations` and `incomplete`
- cross-domain redirect flag
- resumable per-domain output

Before freezing protocol v1.0:

1. run a 100-domain pilot with timing instrumentation;
2. quantify sitemap-discovery cost and choose a fixed budget if needed;
3. decide the primary handling of cross-domain redirects;
4. settle the final Tranco frame (preferably the IWSS frame if it can be recovered);
5. perform another manual manifest review before the 500-domain pilot.
